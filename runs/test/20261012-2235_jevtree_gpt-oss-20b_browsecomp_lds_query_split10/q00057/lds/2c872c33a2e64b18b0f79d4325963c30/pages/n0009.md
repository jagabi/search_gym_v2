ExPORTER

 ExPORTER is a key component of the NIH "open government" initiatives to provide more transparency into NIH activities, and to improve the quality and usability of data collected. ExPORTER provides bulk administrative data found in [RePORTER](https://reporter.nih.gov/) to the public for detailed analyses or to load into their own data systems. Generally, files for downloading are provided in CSV formats. The [ExPORTER FAQs](https://report.nih.gov/faqs#exporter) page includes the data dictionary for each file, the data refresh details, and other pertinent information. [CRISP](https://reporter.nih.gov/exporter/crisp) was the predecessor system to RePORTER, and legacy files drawn from this system are provided from FY 1970 to FY 2009. 

 Note: The release of the consolidated Annual RePORTER project file is scheduled annually by the end of January. This timeframe allows for the integration of the most recent grant information, contracts, intramural projects, and interagency agreements. Subsequently, the Annual RePORTER project files will undergo updates upon the release of the President's budget for the fiscal year, incorporating the NIH Spending Categories data (RCDC). Following the announcement, it may take up to three weeks for the updated files to be made available for public access. 

 The ExPORTER FAQs page includes the data dictionary for each file, the data refresh details, and other pertinent information.
