Una experiencia más rápida de Facebook para Android.

Esta versión de Facebook usa menos datos y funciona en todas las condiciones de red.

#### Facebook Lite:

*   Se instala rápidamente: la aplicación tiene menor tamaño, por lo que se descarga con rapidez y ocupa menos espacio de almacenamiento. 
*   Funciona en teléfonos Android antiguos: puedes usar esta versión en teléfonos Android antiguos que no admiten la aplicación de Facebook habitual. 
*   Usa menos datos: esto aumenta la eficacia de los datos del celular y te permite ahorrar dinero. 
*   Se carga rápidamente: es nuestra aplicación más rápida. Te permite subir fotos de forma más rápida y ver actualizaciones de tus amigos. 
*   Funciona en todas las redes: está diseñada para redes 2G y zonas con conexión a internet lenta o poco estable. 

  

#### Compatibilidad:

 Android 2.2 o superior
