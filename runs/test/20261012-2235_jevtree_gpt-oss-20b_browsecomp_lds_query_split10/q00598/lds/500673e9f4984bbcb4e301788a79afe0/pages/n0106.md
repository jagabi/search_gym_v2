# UC Directory

The online directory houses contact information for many UC departments, faculty, staff, and emeriti. Access to the directory requires a UC username and password.

  

Open the [UC Directory](https://ucdirectory.uc.edu/Secure_Default.asp).

#### UC Website Authors:

The requirement for authentication to the directory is necessary to help safeguard the personally identifiable information of UC faculty, staff, and emeriti by restricting public access to directory information. If your area currently depends on UC Directory data and are impacted by this requirement, Digital Technology Solutions staff will help you identify a more secure way to address your data requirements.

  

To request assistance wtih your site, please submit a "[Report Incident](https://ituc.service-now.com/sp?id=sc_cat_item&sys_id=f71e2c1c1b41cc54432b0d0fdc4bcb57&sysparm_category=590409b81b09c894432b0d0fdc4bcb86)" ticket to the IT Service Desk.
