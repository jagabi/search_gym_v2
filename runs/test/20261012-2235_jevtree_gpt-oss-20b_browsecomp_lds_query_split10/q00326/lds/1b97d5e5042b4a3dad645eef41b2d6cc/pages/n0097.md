Wildcards
?re?d Replaces a **single character**, so documents returned would contain 'reid', 'reed', etc.
*ja*son Replaces **multiple characters**, so documents returned would contain 'jackson', 'jamison', etc.
~book~Performs a fuzzy search for a **single term**; returns document containing books, cook, booked, etd.
""~"court monument"~5 Performs a proximity search on **two terms**; returns documents that contain the word 'court' and 'monument **within 5 words** of each other (**don't forget the quotes!**)
