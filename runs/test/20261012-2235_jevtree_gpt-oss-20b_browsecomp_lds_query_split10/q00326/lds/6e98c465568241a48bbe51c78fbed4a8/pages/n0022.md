# WiFi and Wireless Printing

## How to use WiFi inside the Library

**Free wifi** is available from 6 am to 10 pm.

Connect to the**Library-Public**network, and enter this password:**pclibrary**

You must configure your device or laptop yourself. We don't offer detailed tech support for wifi.

Our wifi is open and has no security or anti-virus protections. You should make sure that your device or laptop is protected, as you assume all risks when using the wifi.

You must abide by our Computer and Wifi Use Agreement when using our wifi. Content is filtered on wifi.

*   [Computer and Wifi Use Agreement](https://content.civicplus.com/api/assets/e8a2aa85-31c7-47de-b60e-62664dfbb734)
*   [Filtering information](https://www.library.pima.gov/faqs/Are-there-filters-on-the-computers-or-wifi/ "Filtering information")

## How to use wireless printing

Print jobs can be sent from anywhere to any of our library printers via **email**, **web**, or the **mobile app**, and then picked up from any library, as long as the library is open.

Wireless printing works from any internet-connected device or computer, and you do not need to be on the Library's wifi to send a print job.

Printing costs **$0.10 per side** of page.

Print jobs are held in our system for 24 hours from the moment you send them. You pay once you arrive at the library. [Check your library's hours](https://pima.bibliocommons.com/locations/).

See below for detailed instructions on using wireless printing.

If you need help printing from a library computer, please ask staff for assistance.

## Wireless Printing Instructions

## Upper wifi and wireless printing page buttons

*   [Print instructions](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/04/2026-03-20-ENGLISH-Patron-Wireless-Printing-Instructions.pdf)
*   [Imprimir las instrucciones](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/04/2026-03-20-SPANISH-Patron-Wireless-Printing-Instructions.pdf)

### Option 1: Send via Email

*   Be sure you’re connected to the Internet, you can connect to Library’s free wifi!

* * *

1.   Open the email, photo, or document you want to print.
2.   Email an item or forward an existing email. When forwarding an email be sure to attach the file: 
    *   Grayscale: **BW-PimaCountyPL@ePrintItSaas.com**
    *   Color: **Color-PimaCountyPL@ePrintItSaas.com**

3.   You will receive a confirmation email that includes a release code.
4.   Go to any Library to retrieve your print job. You will use the release code in the confirmation email you received to retrieve your print job. 
    *   Example: If you receive the release code: 12345678. You would type in '12345678' at the print kiosk.

5.   The email and the attachment will print as separate print jobs as long as you selected to forward the attachment with the email. 
    *   **If you want multiple copies of the same document, you must send each copy individually.**

![Image 2](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/02/QR-code-Grayscale-print-email.png)

Scan code to open a grayscale email on your mobile device.

![Image 3](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/02/QR-code-Color-print-email.png)

Scan code to open a color email on your mobile device.

### Option 2: Upload via Website

*   If you’re using a browser on a mobile device, use the steps in OPTION 3 on the next page.

* * *

1.   Go to the Library's Mobile Print Portal:**[library.pima.gov/print-portal](https://www.library.pima.gov/print-portal)**
2.   Enter your name or library card number - this is how you will access your print job at the library print kiosk
3.   If you would like a receipt, enter your email address or mobile number in the spaces provided.
4.   Select any library location (patrons can access their jobs from any location)
5.   Press the Continue button
6.   Upload the file you want to print
7.   Select printing options 
    *   Paper size
    *   Layout
    *   Page range
    *   Number of copies
    *   Select Color or Grayscale
    *   One Sided or Two Sided

8.   Press Submit
9.   Go to any Library to retrieve your print job within 24 hours. You will use the name or library card number you entered in step 2 to retrieve your print job

![Image 4](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/02/QR-code-Portal-link.png)

Scan to go to the Library's mobile print portal.

### Option 3: Send via Mobile App

*   Download and set up the free Mobile App called ePRINTit SaaS

[Get app for **Apple** device](https://apps.apple.com/us/app/eprintit-saas/id6443684419)  
[Get app for **Android** device](https://play.google.com/store/apps/details?id=com.eprintitsaas.mobile&hl=en_US)

* * *

1.   Open the ePRINTit SaaS app
2.   Select any library location (patrons can access their jobs from any location)
3.   Select from the “What would you like to print?” menu
    *   Choose from Selections – Pictures, etc…
    *   Some options will require more configuration

4.   Choose Print Job Settings 
    *   Number of copies
    *   Color or Grayscale

5.   Enter your name or library card number - this is how you will access your print job at the library print kiosk
6.   Press Submit
7.   Go to any Library to retrieve your print job within 24 hours. You will use the name or library card number you entered in step 5 to retrieve your print job

![Image 5](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/02/QR-code-Apple-app-store-link.png)

Scan to go to the Apple Store to get the ePRINTit SaaS app for iOS.

![Image 6](https://www.library.pima.gov/wp-content/uploads/sites/6/2026/02/QR-code-Android-play-store-link.png)

Scan to go to the Google Play store to get the ePRINTit SaaS app for Android.
