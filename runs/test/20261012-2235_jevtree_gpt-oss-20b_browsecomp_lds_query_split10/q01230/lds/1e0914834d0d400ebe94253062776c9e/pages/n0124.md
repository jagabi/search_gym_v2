## Microformat

The HTML markup produced by this template emits an [Geo microformat](https://en.wikipedia.org/wiki/Geo_(microformat) "Geo (microformat)"), which makes the location's [coordinates](https://en.wikipedia.org/wiki/Geographic_coordinate_system "Geographic coordinate system") (latitude & longitude) [parsable](https://en.wikipedia.org/wiki/Parsing "Parsing"), so that they can be, say, looked up on a map. As yet, [the standard for doing this](http://microformats.org/wiki/geo-extension-strawman) for off-world bodies is still under development, but is supported in some microformat parsers (e.g. [Swignition](http://buzzword.org.uk/swignition/)). For more information about the use of [microformats](https://en.wikipedia.org/wiki/Microformat "Microformat") on Wikipedia, please see [the microformat project](https://en.wikipedia.org/wiki/Wikipedia:UF "Wikipedia:UF").

Geo is usually produced by calling {{[coord](https://en.wikipedia.org/wiki/Template:Coord "Template:Coord")}}, and uses HTML classes:

*   body
*   geo
*   latitude
*   longitude
