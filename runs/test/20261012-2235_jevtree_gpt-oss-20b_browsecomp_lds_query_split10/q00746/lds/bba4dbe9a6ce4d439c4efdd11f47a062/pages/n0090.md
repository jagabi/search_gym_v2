### Keyword Search Hints:

Close(X)

The keyword search feature allows you to search using any word. For any keyword that you enter, all matching items will be returned (i.e. a search for "Corn" will yield results for Corn, Sweet Corn, and Popcorn). Once you have initiated a search by keyword, you can then proceed to limit by any other available Selections.

If you enter two or more keywords, the results will include entries for all entered keywords. Example: a search for "apple orange" will yield results for any items containing the word orange OR the word apple.

The keyword search is not case sensitive.

Search is currently only enabled for commodities.

Quick Stats lets you create queries based on the simple filtering rules of _What, Where_, and _When_.

**Select Commodity** is the _What_. Click on a value from any visible item list to start your query. The remaining visible unselected item lists will filter and refresh based on your choices. If the updated fields in the Select Commodity area are satisfactory, you will not have to make more selections in this area unless you want to fine tune your search.

You may begin filtering in Select Commodity, Select Location or Select Time areas. For example, if you want the most recent corn data, you would start by filtering on Select Time.

If you would like to select more than one item in any of the data fields, hold the Ctrl key on your keyboard and click on any other items of the same field that you would like to use. You may also hold the Shift key and select an upper and lower value of a data field to select the entire range.
