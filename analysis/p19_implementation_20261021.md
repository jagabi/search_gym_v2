# p19 코드 반영과 검증

제품 버전: raw-browser-d3-navigation-docling/19. 메인 추론 모델·채점·검색 API·전체 벤치마크는 실행하지 않았다. conda search Python 3.11에서 오프라인 회귀 테스트 및 허용된 Jina/d3 파일럿만 실행했다.

## 변경

- 링크마다 해당 내부 링크 번호가 등장하는 모든 원문 문단과 해당 URL만 평가한다. 단어 기반 순위, 도메인 예외, 생성 요약을 추가하지 않았다. 기존 공유 HTTP wave 한도를 유지하며 실패한 wave 이후 호출은 중단한다.
- 읽기 슬롯은 실제 선택한 목표에 차감한다. 검색어 점수로 고른 문서를 원질문 몫으로 잘못 차감하던 흐름을 고쳤다. 소진된 목표는 다음 문서 순위에 참여하지 않는다.
- 모든 가지가 닫혔고 검색어 근거만 읽은 경우, 현재 도달한 frontier에서 원질문 몫을 재검토한다. 과거 중간 노드로 되돌아가지 않는다. 원질문 점수가 기존 jev_floor(0.15) 미만이면 읽지 않는다. 최종 청크 역시 기존 d3 점수·한도에 따라 선별한다.
- 원질문 몫을 이미 읽었다면 이 추가 검토를 하지 않는다. 예산을 채우려고 쿼리용 읽기를 강제하지 않는다.
- depth 한도에서 불가능한 확장을 권하던 마지막 읽기 안내를 수정했다.

읽기 2회·최대 depth 3·방문 10개·자식 폭 2를 유지했다. 메인모델의 도구와 reasoning 전달 정책도 그대로다.

## 파일럿

| 사례 | 방문 / 실제 최대 depth | 읽기 | d3 호출 / 입력 토큰 | 반환 확인 |
|---|---|---|---|---|
| 516 Kinsey 고정 진입 | 5 / 3 | 2 | 280 / 700,376 | The Fifth Estate 원문은 반환, Peter Nzioki 출연진 청크는 탈락 |
| Nobel Chemistry 1911 고정 진입 | 3 / 2 | 1 | 93 / 138,452 | 7 November 1867, Warsaw 반환 |
| PEP 615 직접 조회 | 1 / 1 | 1 | 42 / 108,158 | Final, 22-Feb-2020 반환 |

516은 기존 링크 축소 파일럿의 읽기 1회·246호출·608,843토큰에서 영화 페이지를 읽는 단계까지 진행했다. 이 사례의 호출·입력 비용은 증가했다. 정답 후보 반환이나 전체 정답률 개선으로 해석하면 안 된다. 출연진 청크의 원질문 점수는 약 0.035로, 여전히 원문 선별에서 탈락한다. 문서 앞 원문 청크를 맥락으로 추가하는 3회 d3 재평가도 했으나 전체 경로/최종 반환을 입증하지 못해 제품에는 반영하지 않았다.

정상 두 사례는 요구 사실 반환과 1회 읽기 종료를 유지한다. 런타임은 서버 부하·동시 파일럿·캐시 차이가 있어 속도 개선률로 보고하지 않는다. 고정 진입점 테스트라 초기 검색 품질이나 메인 최종 답변은 검증하지 않았다.

원시 기록: `analysis/pilots/p19_final/bill_current.*`, 최종 정상 사례는 `analysis/pilots/p19_final_controls/*`. `p19_production` 및 p19_final의 chemistry/direct는 중간 구현 결과이므로 최종 정상 사례로 집계하지 않는다. 516 검증 후 추가한 마지막 조건은 원질문 몫을 이미 읽은 경우만 적용되므로 검색어 몫만 읽은 516의 검증 경로에는 영향을 주지 않는다.

오프라인 RawTree 회귀 테스트: 81개 통과. 변경된 의미에 맞게 반복 정보를 낮게 평가하는 가짜 d3 입력을 수정했고, 검색어 슬롯 차감·중간 노드로 회귀하지 않는 마지막 읽기·내부 링크 번호 1/10 분리·동일 링크 여러 문단 보존을 검증했다.
