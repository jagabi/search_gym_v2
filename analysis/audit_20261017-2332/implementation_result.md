# Progressive v10 적용 및 검증 결과

2026-10-19 기준. 코드 적용과 제한된 실제 모델 검증을 완료했다. 10문제 전체를 재실행한 결과는 아직 없으며, 문제당 20분 이내 달성을 보장하지 않는다.

## 원인과 변경

- 기존 실행은 v9 코드지만 best_first였다. progressive에 구현된 조기 근거 반환과 후속 읽기 도구가 활성화되지 않았다. 실행 시 실제 정책을 출력하고 config.json 및 run.start에 저장한다. 기본 기대 정책과 실행 정책이 다르면 모델 호출 전에 실패한다. 비교 실행은 기대 정책까지 명시적으로 바꿔야 한다.
- 기존 101,222회 d3 요청 중 링크 판정이 78,433회였다. 4개 웨이브는 이미 정상 작동했다. 초기 검색 결과 중 4페이지만 방문하고 본문 2개를 읽어 반환하며, 필요한 경우 저장한 frontier를 이어간다. 링크를 새로 평가하는 부모는 행동당 1개로 제한한다.
- 원질문/검색 목표의 판정 캐시를 개별화했다. 목표만 바뀌어도 동일한 원질문 판정은 재사용한다. 모든 번들을 전부 청크 단위로 읽는 방식으로 바꾸지 않았다.
- 방문하지 않은 검색 결과도 출처 목록에 보존하고 read_source로 읽을 수 있다. 후보·모순·다음 부족한 단서를 담는 research 입력을 필수화했다. 이 스키마가 후보 갱신의 의미적 정확성까지 보장하지는 않는다.
- Jina Reader에 지원 옵션 X-Assert-Status-Code: 200을 추가했다. HTTP 200으로 제공되는 인증 화면까지 모두 식별하는 기능은 아니다. 모델이 접근 불가 출처를 보고하고 URL별 한 번 강제 새로고침하거나 대체 출처를 선택할 수 있다.
- 새로고침으로 실제 본문이 바뀌면 새 출처 버전을 만든다. 이전 인용 원문은 보존하고 이전 버전으로 판단한 조건은 재검증하도록 표시한다. 새로고침 실패만으로 기존 유효 근거를 폐기하지 않는다.
- 최종 검토에 원질문의 수치·연도·관계·연대 확인 및 불가능/가능성 낮음 구분을 반영했다. 자연어 지침이며 오답 제거를 보장하지 않는다.

Reader 옵션 근거: https://github.com/jina-ai/reader/blob/main/src/dto/crawler-options.ts

## 적용값

| 항목 | 값 / 의미 |
|---|---|
| 검색 | 최대 10회 |
| 정책 | progressive / 기대 정책 progressive |
| d3 전송 | HTTP당 판정 1개, 4개 웨이브 전체 완료 후 다음 웨이브 |
| 초기 방문 / 추가 방문 | 4 / 행동당 최대 4 |
| 새 링크 평가 부모 | 행동당 최대 1 |
| 검색별 방문 상한 / 깊이 | 16 / 5 |
| 자동 본문 읽기 | 2개: 원질문 순위 1 + 검색 목표 순위 1 |
| 추가 본문 | 필요할 때 read_source |
| 전체 계획 목표 | 방문 64, 본문 읽기 40, 부모 확장 6 |
| 번들 / 청크 | 5,000 / 512 토큰 |
| 청크 반환 top-k | 원질문 4 + 검색 목표 8, 인접 청크 1 |
| 번들·청크 점수 하한 / 링크 점수 하한 | 0.15 / 0.0 |
| 메인 턴 상한 | 24 |

방문 64·읽기 40·확장 6은 모델에 전달하는 계획 목표이며 강제 종료 조건이 아니다. 전체 문제에 20분 타임아웃을 추가하지 않았다. 기존 개별 요청 타임아웃과 검색/턴/검색별 방문 상한은 존재한다. 링크 점수 하한을 올린 것은 아니므로 낮은 관련도 링크는 여전히 선택될 수 있으나, 확장 작업량과 후속 행동을 제어한다.

실측 평균을 이용한 기존 추정은 검색 10회·방문 64·읽기 40·부모 확장 6회에서 약 17.2분이다. 부모당 링크 약 100개, fetch 4병렬 및 기존 모델 응답시간이라는 가정이 포함된다. 긴 페이지·많은 링크·서버 지연·추가 읽기에 따라 초과할 수 있다.

## 검증

- 오프라인 268개 테스트 통과, 실패/오류 0개: offline_validation.json. 10회 검색 허용, 4개 웨이브 관련 기존 테스트, 정책 불일치 차단, 추가 읽기, 캐시 재사용, 새로고침 및 근거 버전 보존을 포함한다.
- 저장한 q57 논문 원문을 실제 메인 모델과 d3에 전달: 41.50초, d3 112회, 잘못된 도구 호출 0회. Vanderbilt Clinical Oncology Research Career Development Award를 답했다. 검색·네트워크 전체 재현이 아니며 최종 인용은 URL 대신 S1 표기였다. 결과: live_replay_235121/result.json.
- q746 관련 두 출처로 제한한 연대 판단 검사: 52.47초, d3 28회, 잘못된 도구 호출 0회. Rockefeller를 선택했다. 원래 문제 전체를 푼 것이 아니다. 답변에 연대상 불가능/후보 전부라는 과잉 단정이 있어 일반 최종 검토 지침을 보완했다. 이 문구 보완 후 실제 모델 검사는 재실행하지 않았다. 결과: chronology_235530/result.json.
- q598 원래 PDF에 실제 Reader 요청: X-Assert-Status-Code 옵션을 사용하면 원본 503을 Reader HTTP 422 오류로 반환했다. 정상 example.com은 200이었다. 인증을 우회하거나 PDF 내용을 확보한 결과는 아니다. 결과: reader_status_probe.json.
