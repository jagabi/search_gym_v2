# 진단용 10문항 토큰 비교

단위: 실제 토큰 수. 같은 10문항 합계. 기반 모델 gpt-oss-20b의 메인/reader 등 호출 포함. 채점 제외.

| 방법 | 점수 | 입력 | 출력 | 입력+출력 |
|---|---:|---:|---:|---:|
| JEV method | 7/10 | 4,300,510 | 341,580 | 4,642,090 |
| search-o1 | 7/10 | 5,234,497 | 451,571 | 5,686,068 |
| RAgent | 7/10 | 1,290,834 | 36,511 | 1,327,345 |
| DS frozen | 6/10 | 6,199,709 | 280,599 | 6,480,308 |
| DS v3 | 5/10 | 3,143,333 | 194,702 | 3,338,035 |
| DS v4 | 7/10 | 2,755,974 | 173,111 | 2,929,085 |
| DS v6 | 7/10 | 1,720,033 | 78,677 | 1,798,710 |
| DS v8 | 7/10 | 4,802,698 | 488,594 | 5,291,292 |

별도 JEV API: 입력 21,899,066, 출력 723,357.
JEV 방식의 두 모델 합산: 27,264,513토큰. 서로 다른 토크나이저/단가이므로 비용 배수가 아니다.

| JEV 방식 내 gpt-oss 역할 | 입력 | 출력 | 호출 |
|---|---:|---:|---:|
| reader | 2,906,266 | 299,803 | 235 |
| condition extraction | 3,039 | 10,560 | 11 |
| main (total minus other roles) | 1,391,205 | 31,217 | 73 |

출력은 서버 completion_tokens 기준. reasoning_tokens는 추정치일 수 있어 별도로 더하지 않는다.
JEV 값은 jev.result usage 합계이며 요약의 jev_input_tokens와 일치한다. 실패한 요청에서 미보고된 사용량은 알 수 없다.
비교 목적의 재현 데이터는 동명 JSON 파일에 저장했다.
