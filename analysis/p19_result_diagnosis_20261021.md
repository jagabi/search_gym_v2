## Depth: 방문과 읽기는 늘었으나 성공 원인을 구분해야 한다

| depth | p18 방문 / 성공 preview / 읽기 | p19 방문 / 성공 preview / 읽기 |
|---|---|---|
| 1 | 422 / 293 / 79 | 382 / 262 / 84 |
| 2 | 16 / 14 / 2 | 18 / 17 / 5 |
| 3 | 2 / 2 / 0 | 4 / 4 / 1 |

실제 하위 depth 읽기는 2→6회다. p19 읽기 90회 중 84회(93.3%)는 여전히 depth 1이다. 성공 preview 기준 하위 depth가 관찰된 검색은 7/76→9/74회다. fetch 실패까지 포함한 문항 최대 depth와는 다를 수 있다.

516의 실제 성공 흐름:

1. 검색 4에서 Police(2005)→Indrajith→다른 가족·작품으로 확장했으나 정답 경로가 아니다.
2. 검색 5에서 The Constant Gardener→배우 페이지→Eastern Promises를 depth 3에서 읽었다. 이 역시 정답 경로가 아니다.
3. 검색 7 `Bill Condon 2013 thriller film`의 **depth 1** The Fifth Estate 및 Letterboxd 출연진에서 Peter Nzioki / Peter King Nzioki를 실제 반환했다.
4. 검색 8 `Peter King Nzioki born`에서 **depth 1** 인물 페이지와 다른 기사로 부모·출연작 등을 반환하고 정답을 냈다.

따라서 516을 깊이 3 탐색의 성공으로 설명하면 안 된다. 후보 원문이 메인에 전달된 것은 확인됐지만, 앞선 고정 Kinsey 파일럿과 검색어·진입점이 다르므로 그 파일럿 실패가 동일 조건에서 해결됐다는 증거도 아니다.

1196은 검색 6에서 constituency→도시 페이지를 depth 2로 따라가 실제 읽었다. 다만 앞서 검색 4·5 등에서 이미 후보 도시가 드러난 뒤의 확인 경로다. depth 2에서 최초 식별했다고 해석하지 않는다.

516 최종 답변은 출생일을 1978년으로 쓰면서 Goat 조건도 충족한다고 단정했다. 반환 기사에는 1979년생이라는 상충 정보도 있었다. 인물 식별 정답과 모든 조건의 검증 성공은 구별해야 한다.

## 남은 실패

### 57: 정답 논문 접근 실패 + 빈 final

정답 논문 PMC7227421은 찾았다. 그러나 같은 PMC 주소가 7회, PubMed 31652074가 4회 실패했다. Jina 응답은 HTTP 422이며, 내부 메시지는 `Expected status code 200 but got 203`이다. 출판사 주소는 원사이트 403을 보고했다. Reader가 전달한 상태이므로 원사이트 차단의 정확한 메커니즘까지 이 로그로 확정하지 않는다.

반환 원문에는 정답 award가 없었다. 다른 연도·다른 논문과 NETTER-1 자료 등을 읽었다. 마지막 두 번 모두 text와 raw_text가 빈 문자열, finish_reason은 stop이고 reasoning은 있었다. 따라서 이미 생성된 final text를 파서가 버렸다고 볼 근거는 없다. 접근 실패와 마지막 출력 실패가 겹쳤다. p18 정답이 snippet 의존이었다는 이전 진단도 함께 고려해야 한다.

### 598: 올바른 문서 lead를 얻고도 메타데이터 조회로 이어지지 않음

정답 PDF `RRS_10_2013_a1en.pdf`가 검색 4·5·6·9에 노출되고 실제 접근도 4회 시도됐다. Jina HTTP 422 / 내부 메시지는 원사이트 503이다. 현재 로그에서는 PDF라서 파싱에 실패했다는 증거가 아니다.

검색 결과의 제목 일부 `statistical evaluation of regional differences regarding ...`, 2013년, MOROŞANU, Elisabeta Jaba 감사 문구가 **access_failed lead로 메인에 전달**됐다. 그러나 다음 검색은 제목·저자·연도로 출판정보를 찾는 대신 HDS/교수/극장 단서를 반복했다. 본문 접근 자체는 환경 문제로 남겨도, 이미 본 구체적 lead를 좁혀 가는 방향은 개선 대상이다. 이번에도 정답 저널은 반환 원문에 없고 최종적으로 찾지 못했다고 답했다.

### 746: 잘못된 가설에서 이탈하지 못함 + 빈 final

첫 검색부터 Kansas를 가정했다. 이후 2014년 corn 수치를 여러 번 다시 검색했으며, vice president 검색에서 Hannibal Hamlin을 읽었다. 주·연도·인물 관계가 확립되지 않은 상태에서 다음 단서를 연결했다. 원문의 Kansas 외 후보나 시간적 충돌을 검증하는 진전 없이 검색 한도를 썼다. 실제 하위 depth 진입은 없다.

첫 검색에서 d3 RemoteProtocolError 2회가 있었고 한 페이지 판단이 실패했다. 그 이후 9개 검색은 이어졌다. 이 단발 오류만으로 전체 실패를 설명할 수 없다. 마지막 두 final 모두 raw_text/text가 빈 문자열이었다. Person A나 Japan 체류를 독립적으로 확인한 새 근거는 이번 로그에도 없다.

### 1230: 연도·수치·측정 정의를 지키지 못함

200~210시간 단서에서 여러 연도·측정의 보고서를 읽은 뒤, 2019년 게시된 USA Today 자료의 Moscow 210 / St Petersburg 200을 근거로 조건에 맞는 도시가 없다고 결론 냈다. 게시 연도와 측정 연도, 정체 시간과 이동 시간, 열린 구간의 양 끝값을 분리해야 한다. 반환 자료가 조건 범위의 모든 도시를 포괄하지도 않는다.

최종 검색은 이미 잘못 제한한 `Moscow theater built 1930 ...`였다. 정답 Mumbai/Regal 근거는 반환되지 않았다. 질문 문구와 닮은 Instagram popular 페이지도 원문으로 반환됐다. 이런 텍스트는 독립된 통계·극장 이력을 입증하지 않는다. 단순히 depth 상한을 늘려 해결될 유형이라고 볼 수 없다.

## 시간과 비용

저장된 검색 작업 시간 합은 4,594.2→4,077.3초다. 문항 latency 합에서의 감소 560.4초 중 검색 작업 시간 차이는 약 516.9초다. 검색 시간에는 fetch·d3·로컬 청킹 등이 섞여 있다.

d3 응답 평균 서비스 시간은 약 1,624→1,285ms로 감소했다. 반면 40번은 929→1,814ms로 증가했고 읽기도 3→4회가 됐다. 366번도 서비스 시간이 718→1,213ms로 증가했다. 쉬운 문제까지 일관되게 빨라졌다고 할 수 없는 이유다. 병렬 요청의 서비스 시간을 합쳐 wall time으로 해석하지 않았다.

질문 단위 d3 평가 수:

- bundle: 460→660, chunk: 2,752→3,956.
- 읽기 선택 재평가: 36→246.
- 링크: 542→643.
- entry+entry diversity: 1,777→1,568.

추가 읽기와 재평가가 호출량을 늘렸다. p19 전체 평가의 절반 이상은 bundle/chunk다. 링크 입력 축소의 제한된 토큰 절감 효과와 전체 시스템 비용 증가를 함께 봐야 한다.

## 다음 변경의 우선순위 제안

1. 로그에 이미 보인 구체적인 문서 lead를 다음 검색 목표로 이어가는 짧은 메인 프롬프트. 598처럼 접근 불가 문서를 반복 재발견하는 흐름을 줄인다. 접근 우회 기능은 필요하지 않다.
2. d3의 원문 선별에서 각 요청 관계를 만족하는 후보 집합과 원자료의 연도·측정 정의를 보존하는 기준. 516처럼 검색어가 달라지면 출연진 선택이 달라지는 불안정성과 1230의 자료 혼동을 같이 봐야 한다.
3. 읽기/종료 변경을 더 넓히기 전에 쉬운 문제의 중복 읽기·재평가 비용을 줄일 구조를 검토한다. 현재는 비용 증가가 확인됐고 깊이 경로의 유효성은 아직 약하다.
4. 빈 final은 별도로 해결해야 한다. 다만 이번에는 원래 답변 근거도 부족한 두 문항이므로, 빈 답변만 없애면 정답이 된다고 주장하지 않는다.

현재 추가 코드 수정이나 실험은 하지 않았다. 후속 실험은 사용자 서버 실행 결과로 확인한다. 집 네트워크에서 서비스 호출은 하지 않는다.
